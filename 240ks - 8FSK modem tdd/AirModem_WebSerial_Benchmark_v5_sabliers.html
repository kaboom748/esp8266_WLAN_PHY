AirModem WebSerial — Banc d'essai v4 + sabliers

Débit TX → RX réellement vérifié, latence, jitter, RTT, pauses XON/XOFF et diagnostic du goulot d'étranglement.

Configuration du projet : deux ESP8266 · 8-FSK · TDD 280 ms · UART 19 200 bauds, 8N1, XON/XOFF logiciel · AIRMODEM_DIAGNOSTICS=0. Ferme PuTTY et Arduino Serial Monitor. Utilise Chrome/Edge via localhost ou HTTPS. Les XOFF récurrents sont normaux autour des créneaux TDD ; leur compteur seul n'est pas une panne.

Journal et autotest

Limites : le navigateur ne voit pas les trames RF internes, le temps de file dans chaque ESP ni les retransmissions. Le débit correspond aux **octets du protocole de benchmark validés à l'arrivée**, pas au débit radio brut. La latence inclut JavaScript, USB, UART, TDD et files modem ; le jitter est la médiane des écarts absolus entre latences successives. Les données utilisateur 0x11/0x13 sont échappées ; la compatibilité réelle de Web Serial avec l'USB-série dépend du pilote et du matériel. Une boucle A→B→A mesurée par le navigateur est un RTT applicatif.
